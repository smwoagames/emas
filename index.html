Cara baca & had data

BUYERS ABSORBED: pembeli masuk dengan volume besar di puncak, tetapi harga tak mampu naik lagi. Penjual pasif (limit sell) menyerap belian itu. Selalunya diikuti penurunan.

SELLERS ABSORBED: penjual masuk dengan volume besar di dasar, tetapi harga tak mampu turun lagi. Pembeli pasif menyerap jualan itu. Selalunya diikuti kenaikan.

Bubble muncul bila volume candle sekurang-kurangnya 2.2× (Biasa) atau 3× (Ketat) median 30 candle sebelumnya. Absorption disahkan bila 3 candle seterusnya gagal melepasi puncak/dasar itu dan harga tutup ke arah bertentangan. Zon dikira pecah bila candle tutup melepasi zon.

Dinding di zon: jumlah limit order di zon (jual untuk BUYERS ABSORBED, beli untuk SELLERS ABSORBED), dari order book setiap minit. Setiap kali harga masuk semula ke zon, page bandingkan dinding sebelum dan selepas. BERTAHAN = order masih ada ≥70%. DIISI SEMULA = volume yang didagang lebih besar daripada order yang kelihatan, tapi order masih ada; maknanya ada pihak yang terus menambah order (absorption paling kuat). DIMAKAN = order tinggal kurang 40%, zon mungkin pecah. Gred: KUAT (bertahan/diisi semula), SEDERHANA (ada dinding, belum diuji), LEMAH (berkurang bila diuji), TIADA (kurang $2 ribu).

Anak panah BUY / SELL muncul pada ujian kedua (atau seterusnya) yang dinding zon bertahan atau diisi semula. Kalau dinding dimakan, kiraan bermula semula: ia perlu bertahan 2 kali lagi. ▲ BUY di zon SELLERS ABSORBED (pembeli pasif di bawah), ▼ SELL di zon BUYERS ABSORBED (penjual pasif di atas). Harga anak panah = harga buka minit selepas order book mengesahkan dinding masih ada. Anak panah lama kekal di carta walaupun zon kemudian pecah, supaya awak nampak yang gagal juga. Ini tanda bacaan pasaran, bukan jaminan; zon dikira gagal bila candle tutup melepasi zon.

Sejarah order book hanya dikumpul semasa page terbuka (disimpan dalam pelayar ini sehingga 3 jam), jadi ujian sebelum page dibuka tidak dapat dinilai. Bar di tepi kanan carta = order book sekarang (merah jual, hijau beli).

"Kadar menjadi" = berapa banyak absorption yang bergerak sekurang-kurangnya 1 purata julat candle ke arah jangkaan sebelum zon pecah, dalam data yang dimuat. Sampel kecil, jadi angka ini hanya gambaran.

Sumber data: terus dari API awam Hyperliquid. Setiap kali page dibuka, 3 hari candle 1 minit dimuat semula, jadi tiada lubang walaupun page ditutup lama. Selepas itu candle, order book dan dagangan datang secara live. Telefon menghentikan page di latar belakang; bila dibuka semula, page muat semula sejarah dan sambung semula.

Beli/jual sebenar: semasa page terbuka, setiap dagangan datang dengan arahnya (market buy atau market sell). Bubble untuk minit itu guna peratus sebenar ("sebenar" dalam kotak butiran). Untuk candle sebelum page dibuka, arah masih dianggar daripada bentuk candle ("anggaran").

Order book: 20 level terdekat pada harga penuh, ditambah level $1 lebih jauh. Bilangan dalam kotak butiran ialah bilangan order, bukan wallet. Sejarah order book (untuk semakan dinding dan anak panah) hanya dikumpul semasa page terbuka, disimpan dalam pelayar sehingga 3 jam.

Had: volume datang dari pasaran emas Hyperliquid sahaja, bukan COMEX atau broker anda. Page ini alat bantu baca pasaran, bukan isyarat beli atau jual.
